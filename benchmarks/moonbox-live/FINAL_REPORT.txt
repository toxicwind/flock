SECTION 4: API ARCHITECTURE (Execution Trajectory)
================================================================================

Derived Domain: d4 = "Connect-RPC over HTTP/2 with SPA Fallback"
Confidence: c4 = 0.90

The API uses Connect-RPC (a protocol by Connect RPC, Inc.) which bridges
gRPC and REST. Metrics exposed 87 RPC methods across 51 services.

Key Services:
- kimi.gateway.membership.v2.MembershipService
  - GetCurrentUser, GetSubscription, EarmarkCredit, FinalizeCredit
- kimi.gateway.membership.v2.GiftcardService
  - ListGiftcardCodes, ListGiftcardClaims
- kimi.gateway.promotionalasset.v1.PromotionalAssetService
  - ListPromotionalAssets
- kimi.credentials.v1.APIKeyService
  - GetAPIKeyByUser, CreateAPIKey, DeleteAPIKey
- kimi.auth.v1.AuthService
  - VerifyToken

Execution Trajectory:
1. Client sends POST to /Service/Method with Content-Type: application/json
2. Server validates JWT via warden service (172.29.160.117:443)
3. If JWT valid, request is routed to backend microservice
4. If JWT invalid, returns 401 with Connect-RPC error details
5. If path doesn't match any RPC method, SPA router returns
   "Found. Redirecting to /" (HTTP 200 with HTML meta refresh)

State Invariants:
- Connect-Protocol-Version: 1 header required
- Authorization: Bearer <token> format
- Token must be valid JWT with correct signature and claims

Failure Vectors:
- SPA catch-all masks 404 errors (returns 200 with redirect HTML)
- Token is session-bound and expires when chat session ends
- Dev gateway (agent-gw-dev.dev.kimi.team) has different auth requirements
- gRPC/HTTP2 endpoints bypass the SPA router entirely

> [Note: Connect-RPC is a protocol that lets gRPC services be called via
> standard HTTP/1.1 or HTTP/2, using either JSON or binary protobuf payloads.
> The "SPA catch-all" is a Single Page Application routing pattern where
> unknown paths return the main app HTML, and client-side JavaScript handles
> the routing. This makes it hard to distinguish between a valid endpoint
> and a non-existent one using simple HTTP status codes.]
