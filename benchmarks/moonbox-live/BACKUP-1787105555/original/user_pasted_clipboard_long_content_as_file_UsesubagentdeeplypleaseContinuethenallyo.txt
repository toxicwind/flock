4. Git Operations with PAT

Clone (bare + worktree pattern):

```bash
PAT="REDACTED"
REPO="toxicwind/REPO_NAME"
GIT_DIR="/mnt/agents/output/.git_repos/REPO_NAME.git"
WORK_TREE="/mnt/agents/output/REPO_NAME"

git clone --bare "https://${PAT}@github.com/${REPO}.git" "${GIT_DIR}"
mkdir -p "${WORK_TREE}"
git --git-dir="${GIT_DIR}" --work-tree="${WORK_TREE}" checkout main
```

Commit and push:

```bash
git --git-dir="${GIT_DIR}" --work-tree="${WORK_TREE}" add -A
git --git-dir="${GIT_DIR}" --work-tree="${WORK_TREE}" commit -m "message"
git --git-dir="${GIT_DIR}" --work-tree="${WORK_TREE}" push origin main --force-with-lease
```

Set remote if missing:

```bash
git --git-dir="${GIT_DIR}" remote add origin "https://${PAT}@github.com/${REPO}.git"
```

5. API Operations with PAT

List repos:

```bash
curl -s -H "Authorization: token ${PAT}" \
  "https://api.github.com/user/repos?per_page=100&type=all" \
  | python3 -c "import sys,json; [print(r['full_name']) for r in json.load(sys.stdin)]"
```

Search code:

```bash
curl -s -H "Authorization: token ${PAT}" \
  "https://api.github.com/search/code?q=QUERY+language:go&per_page=10" \
  | python3 -c "import sys,json; d=json.load(sys.stdin); [print(i['html_url']) for i in d.get('items',[])]"
```

Get raw file:

```bash
curl -s -H "Authorization: token ${PAT}" \
  "https://raw.githubusercontent.com/toxicwind/REPO/main/PATH"
```

Create/update file:

```bash
CONTENT=$(base64 -w0 <<< "file content")
curl -s -X PUT -H "Authorization: token ${PAT}" \
  -H "Content-Type: application/json" \
  -d "{\"message\":\"update\",\"content\":\"${CONTENT}\"}" \
  "https://api.github.com/repos/toxicwind/REPO/contents/PATH"
```

7. Important Notes

- Token expiration: Fine-grained PATs expire. Check `https://github.com/settings/tokens`
- Rate limit: 5,000 requests/hour for authenticated requests
- Git LFS: If repo uses LFS, ensure `git-lfs` is installed
- Private repos: Token must have `repo` scope for private repositories
- 2FA: If 2FA is enabled, PAT is required for HTTPS Git operations
- Never expose: This token grants full repo access. Do not log to public channels.
