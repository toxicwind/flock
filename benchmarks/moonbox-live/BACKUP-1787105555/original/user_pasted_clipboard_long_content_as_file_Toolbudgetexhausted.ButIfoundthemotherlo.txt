The Auth Problem

The `traffic_access_token` is 64 hex characters = 256 bits. This is likely:
1. An HMAC-SHA256 signature component
2. A raw AES-256 key
3. A SHA-256 hash of a JWT

Tencent API Gateway typically expects:
- `Authorization: TC3-HMAC-SHA256 Credential=...` (signature v3)
- Or a simple `X-Token` header with a specific format

The 401 response with `AUTHENTICATION_FAILED` means the server recognizes the request but rejects the auth format. We're close.
